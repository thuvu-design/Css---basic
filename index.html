CSS Selector Playground

Designing with CSS Selectors

CSS selectors allow us to choose specific HTML elements and control how they appear on a webpage. We can change typography, color, spacing, backgrounds, borders, and many other visual properties.

Some selectors target every element of a particular type, while others allow us to target specific elements or groups of elements. Learning how selectors work gives us much more control over the visual design of a webpage.

NOTE: As you follow along, experiment with the values. Try changing colors, type sizes, spacing, and other properties to see how the browser responds.

Element Selectors

An element selector targets every instance of a particular HTML tag. For example, a rule using the paragraph selector will affect every paragraph on the page unless another more specific rule overrides it.

NOTE: CSS becomes much easier to understand when you make one change at a time and immediately preview the result in the browser.

Classes and IDs

Classes and IDs give us more specific ways to select elements. Classes can be reused on multiple elements, while an ID should identify one unique element on a webpage.

Class Selectors

A class selector begins with a period in CSS. Classes are useful when several elements should share the same visual style.

ID Selectors

An ID selector begins with a hashtag in CSS. IDs are useful when you need to identify and style one unique element.

Experiment

The best way to learn CSS is to experiment. Change the code, refresh the page, and observe what happens. If something does not work, inspect the selector, property, value, punctuation, and file path before assuming the entire page is broken.
